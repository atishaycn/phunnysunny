About this tool

Public creator use

This is a public tool for TikTok creators. Connect your own account, create slideshow-style videos with captions and images, preview the result, and submit approved content to your own TikTok profile. No internal or admin-only features.

Products & scopes

We use TikTok Login Kit for OAuth sign-in, user.info.basic to display your connected account, and the Content Posting API with video.publish to submit videos that you explicitly approve.

Sandbox demo

The "Connect TikTok" and "Post" buttons in this interface run in sandbox/test mode. They simulate the OAuth flow and publish request without hitting production APIs. Real OAuth credentials are never embedded in this page.

User data handling

We use TikTok account data only to provide the connected posting workflow. We do not sell TikTok data. You can revoke access from TikTok settings or request deletion through our data deletion page. See our privacy policy for full details.
