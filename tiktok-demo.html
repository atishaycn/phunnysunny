TikTok developer review demo

Connect TikTok, review a slideshow, publish through the Content Posting API.

This page shows the complete website flow for Login Kit, user.info.basic, Content Posting API, and video.publish. Use it for the review screen recording.

Terms Privacy
TikTok account Not connected
Login Kit OAuth authorization
Scope user.info.basic
Content Posting API Direct video publish
Scope video.publish
01

Connect TikTok

The user clicks Connect TikTok and is sent to TikTok OAuth. TikTok asks for the selected scopes, then redirects back to this site.

TikTok OAuth request response_type=code scope=user.info.basic,video.publish redirect_uri=https://phunnysunny.com/tiktok-demo
02

Confirm account

After OAuth, PhunnySunny uses user.info.basic to show which TikTok account is connected before any post is created.

PS
Waiting for connection No TikTok account connected yet.
03

Review video and caption

The user reviews the generated slideshow video, caption, privacy level, and AI-generated content disclosure before publishing.

04

Publish request

When the user clicks publish, the app uses video.publish and sends the video to TikTok's Content Posting API.
